# HiChord — Pocket Studio

Browser chord synthesizer with a 2D instrument panel, Web Audio synthesis, effects, sequencer, six recording tracks, local persistence and WAV export.

Live site: https://rockky666.github.io/hichord-web/

Independent adaptation inspired by HiChord. It does not include Pocket Audio firmware or original samples. Recordings stay in your browser.

Static site: no build step. GitHub Pages serves the main branch root. Open through HTTPS or a localhost server for AudioWorklet recording.
